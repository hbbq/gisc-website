The ATP-1 Target Programming Interface is a fixed programming adapter for 8-pin AVR target devices using the standard 6-pin AVR ISP interface.

ATP-1 provides deterministic signal routing between the programmer and target device, eliminating repeated manual wiring and reducing the risk of connection errors during development and programming operations.

The ATP-1 is currently under development.
